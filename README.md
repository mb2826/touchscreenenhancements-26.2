# Touch Screen Enhancements for Minecraft 26.2 (Fabric)

Improvements to the touch screen experience for Minecraft Java Edition 26.2.

Port of [Touch Screen Enhancements](https://modrinth.com/mod/touchscreenenhancements) (originally for 1.21.10 by Jab125) to Minecraft 26.2 / Fabric.

## Features
- Fixes rapid camera spin when using touch screens (Steam Deck / handheld PCs)
- Clickable hotbar slots (tap to select)
- Clickable crosshair (tap screen center to interact / attack)
- Fully configurable (enable/disable features)
- Mod Menu config screen support

## Requirements
- Minecraft **26.2**
- Fabric Loader >= 0.19.3
- Fabric API (0.152.x+26.2 or newer)

## Installation
1. Install Fabric Loader for 26.2
2. Put Fabric API and this mod jar into the `mods` folder
3. Launch the game

## Building from source
```bash
./gradlew build
```
Output jar will be in `build/libs/`.
